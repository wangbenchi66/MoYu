# TransBrowser 使用说明

## 功能特性

- 多标签页浏览
- 自定义新标签页（快捷网站 + 历史记录）
- 全局热键（Boss键、透明度调节、穿透模式等）
- 系统托盘图标
- 无边框/透明背景
- JS 编辑器（可在当前页面执行自定义脚本）
- INI 配置文件迁移

## 快捷键默认值

| 功能 | 快捷键 |
|------|--------|
| Boss键（隐藏/显示） | Alt+Q |
| 透明度增加 | Alt+Right |
| 透明度减少 | Alt+Left |
| 透明度重置 | Alt+Up |
| 穿透模式切换 | Ctrl+Alt+T |
| 返回上页 | Alt+Shift+Z |
| 运行JS编辑器 | Alt+Shift+C |

## 设置说明

通过右上角 ⚙ 按钮或托盘图标右键菜单 → 设置，可修改所有选项。

### 窗口设置
- **透明度**：0.01~1.0
- **总在最前**：始终置顶
- **无标题栏**：隐藏标题栏（可配合鼠标悬停显示）
- **鼠标悬停显示标题栏**：鼠标移到顶部时显示标题栏

### 浏览器设置
- **默认网址**：启动时加载的页面（空则打开新标签页）
- **User Agent**：自定义浏览器标识
- **屏蔽图片/视频**：NoImageMode，节省流量
- **透明背景**：网页背景透明
- **手机模式**：使用移动端 UA

### 自动脚本
每次页面导航完成后自动执行的 JavaScript 代码。

## 新标签页
支持添加/删除自定义网站快捷方式，并显示最近浏览历史（可搜索）。

## INI 配置迁移
如果在程序目录或 AppData 中存在 `config.ini`，程序启动时会自动迁移到 JSON 格式，原文件重命名为 `config.ini.migrated`。
