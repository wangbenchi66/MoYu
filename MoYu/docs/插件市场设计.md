# 插件市场设计文档

## 一、概述

将 MoYu 的站点规则系统从「本地打包」扩展为「本地 + 远程插件」，用户可通过插件市场浏览、安装、管理第三方站点增强脚本。

## 二、整体架构

```
后端 API（元数据接口 + 脚本下载）
        ↓ 元数据列表 / 单个脚本下载
前端插件市场页面（浏览、安装、管理）
        ↓ 安装时下载脚本内容
electron-store（本地持久化已安装插件）
        ↓ 应用启动时加载到内存
内存规则列表（与本地规则合并）
        ↓ dom-ready 时匹配
webview 注入（runWebviewCss / runWebviewJS）
```

## 三、后端 API 设计

### 3.1 插件列表

```
GET /api/plugins
```

返回轻量元数据，不含完整脚本：

```json
[
  {
    "id": "zhihu-enhance",
    "name": "知乎增强",
    "description": "去广告、优化排版、增强阅读体验",
    "author": "MoYu官方",
    "version": "2.1.0",
    "downloads": 1280,
    "tags": ["去广告", "阅读"],
    "pattern": ["zhihu.com"],
    "scriptUrl": "https://your-server.com/plugins/zhihu-enhance.js",
    "icon": "https://your-server.com/plugins/icons/zhihu.png",
    "updatedAt": "2026-05-10T08:00:00Z"
  }
]
```

### 3.2 批量更新检查

```
POST /api/plugins/check-update
Content-Type: application/json
```

请求体：

```json
[
  { "id": "zhihu-enhance", "version": "2.0.0" },
  { "id": "weread-enhance", "version": "1.3.0" }
]
```

返回需要更新的插件（id + 最新元数据 + scriptUrl）：

```json
[
  {
    "id": "zhihu-enhance",
    "version": "2.1.0",
    "scriptUrl": "https://your-server.com/plugins/zhihu-enhance.js"
  }
]
```

### 3.3 脚本下载

脚本本身作为静态文件存放在服务器上，通过 HTTP 直链访问：

```
GET https://your-server.com/plugins/zhihu-enhance.js
```

安装插件时，前端通过 `fetch` 下载脚本内容并存储到本地。

### 4.3 usePlugins.js 状态管理设计

```js
// 核心状态
const installedPlugins = ref([])   // 已安装插件列表（从 electron-store 加载）
const availablePlugins = ref([])   // 远程可用插件列表（从 API 获取）

// 核心方法
fetchAvailablePlugins()     // GET /api/plugins，拉取列表展示
installPlugin(pluginMeta)   // fetch scriptUrl → 存入 electron-store → 加入内存
uninstallPlugin(id)         // 从 electron-store 删除 → 从内存移除
togglePlugin(id)            // 启用/禁用
checkForUpdates()           // POST /api/plugins/check-update → 静默更新
getMatchedRules(url)        // 返回匹配当前 URL 的所有规则（本地 + 远程）
```

### 4.4 规则聚合层改造

`src/rules/providers/index.js` 目前合并三类规则：site / settings / toolbar。

新增第四类：plugins 规则。改造后聚合顺序：

```
1. 本地打包规则（src/rules/scripts/）
2. 远程插件规则（从 electron-store 加载，enabled=true 的）
3. 设置规则（settingsRules）
4. 工具栏规则（toolbarRules）
```

同域名冲突时优先级：本地 > 远程（或按版本号更新的优先）。

## 五、本地存储结构

存储在 electron-store 中，键名 `plugins/installed`：

```json
{
  "zhihu-enhance": {
    "id": "zhihu-enhance",
    "name": "知乎增强",
    "author": "MoYu官方",
    "version": "2.1.0",
    "pattern": ["zhihu.com"],
    "scriptContent": "export const pattern = ['zhihu.com'];\nexport default function(helper) { ...完整脚本内容... }",
    "enabled": true,
    "installedAt": "2026-05-15T10:00:00Z"
  }
}
```

`scriptContent` 存完整的脚本文本，应用启动时通过 `new Function()` 或动态 `import` 转为可执行函数。

## 六、插件脚本格式

与现有 `src/rules/scripts/*.js` 完全一致：

```js
export const pattern = ['example.com'];

export default function main(helper) {
  helper.runWebviewCss('unique-id', `...css...`);
  helper.runWebviewJS(`(() => {
    try {
      // 逻辑
    } catch(e) {}
    return true;
  })();`);
}
```

插件作者无需学习新格式，直接复用现有规则文件结构。

## 七、插件生效时机

```
用户打开网页 → webview dom-ready → 规则匹配
  → 查本地规则（src/rules/scripts/）→ 命中则注入
  → 查远程插件（electron-store，enabled=true）→ 命中则注入
```

安装/卸载后不需要重启应用，刷新当前网页即生效。

## 八、更新检查流程

```
应用启动
  → 读取所有已安装插件的 { id, version }
  → POST /api/plugins/check-update
  → 返回需要更新的列表
  → 对每个需更新的插件：fetch scriptUrl → 覆盖 electron-store 中的 scriptContent 和 version
  → 静默完成，下次访问对应网站自动使用新版本规则
```

## 十、实施优先级

| 阶段 | 内容 | 工作量 |
|---|---|---|
| P0 | 后端 API：插件列表 + 脚本下载 + 更新检查 | 后端 |
| P1 | `usePlugins.js` 状态管理 + electron-store 存储 | 中 |
| P2 | 规则聚合层改造（providers/index.js） | 小 |
| P3 | `PluginPage.vue` 插件市场 UI | 中 |
| P4 | 插件市场入口 + 路由注册 | 小 |

## 十一、注意事项

- **安全**：远程脚本在 webview 中执行，存在 XSS 风险。初期仅允许官方插件，后续考虑审核机制
- **脚本体积**：大脚本（如 5000 行）通过 scriptUrl 单独下载，不走元数据接口
- **离线可用**：已安装插件的 scriptContent 存在本地，断网也能正常生效
- **冲突处理**：同域名本地规则与远程插件都命中时，按版本号或优先级决定
