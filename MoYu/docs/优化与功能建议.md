> - 部分**已随功能删除而消失**（书架/阅读器相关）

| 本文中的条目 | 状态 |
|---|---|
| A3. 多窗口 / 分屏浏览 | **不做** —— `MainPage` 是"单容器 + `v-show` 切换"结构，改造要动 `webviewRefs` 管理模型，收益/成本比不佳 |

## 一、代码缺陷（建议优先修复）

### 1. Tab ID 生成存在碰撞风险
- **文件**: `src/composables/useDesktopApp.js:576, 618`
- **问题**: `createPageTab` 和 `createLocalTextTab` 使用 `Date.now() + random` 生成 ID，未走 `generateUniqueTabId()` 的去重循环。同毫秒创建两个 tab 可能 ID 冲突。
- **修复**: 统一使用 `generateUniqueTabId()`。

### 2. 键盘事件监听器未清理（内存泄漏）
- **文件**: `src/pages/MainPage.vue:1588-1608`
- **问题**: `onMounted` 中添加了 `keydown`/`keyup` 监听器，但 `onBeforeUnmount` 中未移除。HMR 热更新或路由切换时会产生重复监听器。
- **修复**: 在 `onBeforeUnmount` 中移除对应监听器。

### 3. Mac 平台检测竞态条件
- **文件**: `src/layouts/TopBar.vue:7`
- **问题**: `const isMac = window.desktop?.platform === 'darwin'` 在模块加载时求值，但 `preload.cjs` 是异步注入的，可能在模块加载时 `window.desktop` 还未就绪，导致 `isMac` 永远为 `false`。
- **修复**: 改为在 `setup` 或 `onMounted` 中动态读取。

### 4. 文件上传无错误处理
- **文件**: `src/composables/useDesktopApp.js:799`
- **问题**: `uploadLocalFiles` 中 `file.text()` 无 try/catch，一个文件读取失败会中断整个上传循环，已创建的 tab 变成半成品。
- **修复**: 对每个文件独立 try/catch，失败时跳过并提示。

### 5. 设置文件损坏时静默重置
- **文件**: `electron/main.js:188`
- **问题**: `loadSettings` 的 catch 块直接重置为默认值，用户的所有配置（自定义快捷键、站点规则等）无声丢失，无任何提示。
- **修复**: 尝试读取备份，或至少在 UI 中提示"设置已重置"。

### 6. OS 级终止可能被阻止
- **文件**: `electron/main.js:863-869`
- **问题**: `closeToTray` 开启时，`close` 事件 `preventDefault`。若 OS 关机或任务管理器强制关闭，`isQuitting` 为 false，窗口会隐藏而非退出。
- **修复**: 监听 `session-end` 或 `before-quit` 事件，确保 OS 级终止不受阻。

## 二、性能优化

### 1. 历史记录写入无防抖
- **文件**: `src/composables/useDesktopApp.js:95-101`
- **问题**: 每次导航都同步写 `localStorage`（`persistRecentVisits`），最多 200 条数据，高频浏览时阻塞主线程。
- **优化**: 改为 1-2 秒防抖写入，或用 `requestIdleCallback`。

### 2. BottomToolbar 与 MainPage 存在重复处理器
- **文件**: `src/pages/parts/BottomToolbar.vue:122-146`，`src/pages/MainPage.vue:1166`
- **问题**: `onReaderColorInput`、`onFontScaleInput`、`onAutoScrollSpeedInput` 在两个文件中有独立实现。BottomToolbar 版本缺少 `syncWebviewTextColor()` 等同步调用，可能导致 webview 样式不更新。
- **优化**: BottomToolbar 应直接调用 MainPage 暴露的方法，而非维护独立实现。

### 3. MainPage 中 6 个函数用 `arguments` 取参
- **文件**: `src/pages/MainPage.vue:820-900`（`syncWebviewTransparency` 等）
- **问题**: 用 `arguments[0]` 取可选参数，语义不清晰且在严格模式下与箭头函数混用有隐患。
- **优化**: 改为 `function syncWebviewTransparency(tabId)` 带默认参数。

### 4. `forceDisableBlankTargets` 代码重复 120 行
- **文件**: `src/pages/MainPage.vue:534-657`
- **问题**: `forceDisableBlankTargets()` 和 `forceDisableBlankTargetsFor(tabId)` 内联脚本几乎完全一致。
- **优化**: 提取脚本为常量，两个函数只在目标 webview 上不同。

### 5. autoHide 鼠标轮询频率
- **文件**: `electron/main.js:401`
- **问题**: `setInterval(180ms)` 持续轮询鼠标位置，笔记本电池场景下有功耗影响。
- **优化**: 考虑降低频率到 250-300ms，或在窗口不可见时暂停轮询。

## 三、功能建议

### A. 核心体验增强

#### A1. 摸鱼统计增加"专注模式"
- **描述**: 提供一个"专注计时器"（番茄钟），设置 25/50 分钟工作时间，到期后提醒休息。摸鱼统计可对比"专注时长 vs 摸鱼时长"。
- **价值**: 把"摸鱼"从被动记录变为主动管理，提升产品差异化。
- **实现**: 主进程增加 `focusStart`/`focusEnd` 事件，StatsPage 增加对比视图。

#### A2. 摸鱼统计可视化（图表）
- **描述**: StatsPage 当前只有列表和数字。增加：
  - 每日摸鱼时长柱状图（最近 7/30 天）
  - 按小时分布的热力图（几点摸鱼最多）
- **价值**: 直观展示摸鱼习惯，增加趣味性。
- **实现**: 用轻量图表库（如 Chart.js 或纯 CSS 实现），数据已有。

#### A3. 多窗口 / 分屏浏览
- **描述**: 支持左右/上下分屏显示两个 webview，适合对照翻译、边看边写等场景。
- **价值**: 显著提升多任务能力。
- **实现**: MainPage 的 webview 容器改为动态网格布局，`tabs` 数据结构支持分组。

#### A4. 站点快捷方式（PWA 式体验）
- **描述**: 将常用网站"安装"为独立应用窗口，类似 Chrome 的"创建快捷方式"。
- **价值**: 重度摸鱼用户可以将 B站、知乎等固定为独立窗口，不占用 tab 栏。
- **实现**: Electron 的 `BrowserView` 多窗口方案。

### B. 摸鱼安全增强

#### B1. 老板键智能升级
- **描述**: 除一键隐藏外，增加：
  - **伪装模式**: 按老板键后显示一个假的 Excel/Word 文档界面（可配置内容）
  - **声音静音**: 老板键触发时自动静音，恢复时自动取消静音
- **价值**: 当前只隐藏窗口不够自然，伪装界面更符合"摸鱼"场景。
- **实现**: 预渲染一个静态 Excel 模板到隐藏窗口，老板键切换时 `show/hide` 不同窗口。

#### B2. 窗口标题伪装
- **描述**: 允许用户设置窗口标题伪装文本（如 "WPS 表格"），替代真实的 "MoYu"。
- **价值**: 任务栏暴露风险降低。
- **实现**: `win.setTitle()` + 设置项持久化。

#### B3. 访问记录自清理
- **描述**: 提供定时自动清理历史记录的选项（如"保留最近 7 天"）。
- **价值**: 隐私保护，避免摸鱼证据留痕。
- **实现**: `pushRecentVisit` 时顺便清理过期条目，或每日定时任务。

### C. 浏览功能增强

#### C1. 广告拦截
- **描述**: 内置广告拦截规则（基于 EasyList），在 webview 层拦截广告请求。
- **价值**: 摸鱼体验显著提升，减少页面加载时间和视觉干扰。
- **实现**: Electron webview 的 `ses.webRequest.onBeforeRequest` 拦截已知广告域名/URL 模式。

#### C2. 夜间模式（全局暗色）
- **描述**: 对嵌入的网页应用全局暗色滤镜（CSS `filter: invert()`），不依赖站点自身支持。
- **价值**: 夜间摸鱼护眼。
- **实现**: 已有 `noImageMode` 的注入模式可参考，加一条 CSS filter 规则即可。

#### C3. 阅读模式增强
- **描述**: 当前本地阅读器支持 txt。扩展支持：
  - **EPUB 解析与渲染**（用 epub.js）
  - **Markdown 渲染**
  - **PDF 内嵌查看**（Electron 原生支持 PDF）
- **价值**: 摸鱼读书是核心场景，格式支持越多越好。

#### C4. 站点规则市场
- **描述**: 提供一个在线规则仓库，用户可一键导入社区贡献的站点优化规则（去广告、排版优化等）。
- **价值**: 降低规则编写门槛，形成社区生态。
- **实现**: 后端提供规则 JSON API，前端"推荐规则"页面一键安装。

### D. 开发与工程

#### D1. 引入 `@` 路径别名
- **描述**: Vite 配置 `resolve.alias: { '@': path.resolve('src') }`，替代深层相对路径。
- **价值**: 提升可维护性，减少 `../../../` 出错。

#### D2. 设置文件损坏保护
- **描述**: 写入设置前先备份旧文件（`glass-reader-settings.json.bak`），加载失败时尝试恢复。
- **价值**: 防止用户配置意外丢失。

#### D3. 错误上报 / 日志系统
- **描述**: 渲染进程的未捕获异常和关键操作（设置变更、脚本注入失败）写入本地日志文件，方便排查用户反馈。
- **价值**: 当前 `console.warn` 只在 DevTools 可见，打包后无法诊断问题。
- **实现**: 主进程提供 `ipcMain.on('log:write')` 写入 `userData/app.log`。

#### D4. 自动更新完善
- **描述**: 当前更新检测只跳转浏览器下载。可接入 `electron-updater`（配合 GitHub Releases 或自建 OTA 服务）实现应用内自动下载安装。
- **价值**: 用户无需手动下载安装包，更新率提升。
